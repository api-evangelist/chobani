# Chobani

> Chobani is an American food and beverage company founded in 2005 by Hamdi Ulukaya, best known for popularizing strained Greek yogurt in the United States. Its portfolio spans Greek yogurt, oat milk, plant-based yogurt, probiotic drinks, nutritional shakes, and — following the 2023 acquisition of La Colombe Coffee Roasters — ready-to-drink coffee. Chobani is a privately held consumer packaged goods manufacturer and does NOT operate a public developer program: as of 2026-08-02 it publishes no developer portal, no API documentation, no OpenAPI/AsyncAPI/GraphQL contract, no SDKs, no MCP server and no A2A agent card. Retail and distribution partners integrate through EDI and private supply-chain connections rather than an open API.

## API surface

- No public API. Contract discovery run on 2026-08-02 probed www.chobani.com, chobani.com, api.chobani.com, shop.chobani.com and the developer/docs/status/trust subdomains for OpenAPI, Swagger, GraphQL, MCP, llms.txt, security.txt and A2A agent cards. Every canonical path returned 404 or NXDOMAIN; shop.chobani.com returns HTTP 200 with an HTML single-page-app shell for every path and was rejected as a false positive.
- api.chobani.com exists behind Azure Front Door but serves an nginx 404 at the root and is undocumented.
- chobani.com is backed internally by a private, robots.txt-disallowed /api/v1/* surface with no published contract. It is not a public API and was not probed.
- Trading-partner integration with Chobani is done via EDI, not a public API.
